# DSH Snapshot Saver 🛡️

DeepSeek Harness (DSH) 外部插件快照与恢复工具。

## ⚠️ 为什么需要它？
DSH 插件生态早期极其脆弱。安装第三方插件（尤其是 UI 类插件）极易导致宿主加载崩溃、`preset` 丢失甚至整个环境瘫痪。
如果写宿主内部的插件来“自己救自己”，会陷入严重的自举风险（崩溃时防护插件也一起死了）。

本项目采用**纯外部 PowerShell 快照方案**，完全不介入 DSH 生命周期，只在物理层面进行配置备份与重建。

## ✨ 核心功能
- **一键存档 (1-存档.ps1)**：自动结束 DSH 进程，提取当前 `package.json`、`pnpm-lock.yaml`、`cordis.patch.yml` 以及插件清单，打包为独立快照。
- **一键读档 (2-读档.ps1)**：全量覆盖配置文件，删除 `node_modules`，并利用 `pnpm install --frozen-lockfile` 精准重建依赖树。
- **滚动清理**：默认保留最近 5 个快照，避免磁盘膨胀。

## 🚀 使用方法
1. 确保你已经安装了 Node.js 和 pnpm。
2. 将 `1-存档.bat` 和 `2-读档.bat` 放到桌面（需要与 `bin` 目录中的 `.ps1` 路径对应）。
3. **准备折腾新插件前**：双击 `1-存档.bat`。
4. **插件搞崩了环境**：双击 `2-读档.bat`，选择崩溃前的快照，一键回到过去。

## 🚧 边界与限制
- **全量回滚**：只能整体回到某个时间点，无法单独精准剥离某个插件。
- **需要联网**：读档操作依赖网络拉取依赖包（建议挂好代理）。
- **仅限 Windows**：当前基于 PowerShell 和 .bat 构建。
- **不备份不相关文件**：只操作 `profiles\desktop` 下的三个核心配置文件，不涉及全局设置。
